# 算法：时间复杂度速记

| 记号 | 名字 | 例子 |
| ---- | ---- | ---- |
| O(1) | 常数 | 哈希表查值 |
| O(log n) | 对数 | 二分查找 |
| O(n) | 线性 | 遍历一次 |
| O(n log n) | 线性对数 | 快速排序、归并排序 |
| O(n²) | 平方 | 两层循环、冒泡排序 |
| O(2ⁿ) | 指数 | 暴力递归、子集枚举 |

- 估算时只看增长最快的那项，系数和低阶项都扔掉。
- 空间复杂度同理：原地算法 O(1)，哈希表换时间通常 O(n)。
- 面试先说暴力解的复杂度，再说优化到多少，思路分就拿到了。
